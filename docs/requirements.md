# 한글 가로세로 낱말 퍼즐 — 요구사항 명세

> **상태**: 요구사항 확정 · 설계는 [design.md](design.md)
> **버전**: 0.5 · **작성일**: 2026-11-13 · **변경**: v0.2 열린 질문 확정(D11~D14) · v0.3 정답 판정을 단어마다 바로 판정으로 변경(D6·D11) · v0.4 틀리면 입력창을 비움(D11) · v0.5 게임 이름·시각 스타일 기본안 적용(Q9)

## 1. 개요

**한 줄 요약**: 한글 단어로 된 가로세로 낱말 퍼즐 50개를 5단계로 나눠, 단계가 오를수록 조금씩 어려워지게 즐기는 모바일 우선 웹 게임.

### 1.1 목표

- **G1** 한글 단어로만 구성된 퍼즐 50개 (5단계 × 10퍼즐)
- **G2** 단계가 오를수록 단어와 열쇠가 *조금씩* 어려워짐 — 계단식 급상승 없음
- **G3** 마지막 단계도 일반 성인이 상식으로 풀 수 있는 수준 유지 (너무 어려운 단어 배제)
- **G4** 휴대폰에서 한글 입력이 자연스러운 플레이 경험

### 1.2 대상 사용자

일반 성인(전 연령). 한국어 모국어 화자, 상식 수준의 어휘력.

### 1.3 플랫폼

웹 브라우저, 모바일 우선 반응형(PC에서도 플레이 가능). 현재 저장소의 Vite + React 19 + TypeScript 템플릿 위에서 개발.

## 3. 게임 규칙

### 3.1 격자

- 한 칸에 한글 완성형 음절 하나 (`무`·`지`·`개`). 자모 단위 칸은 없음
- 검은 칸으로 단어를 나눔. 가로·세로로 흰 칸이 2칸 이상 이어지면 그 묶음은 반드시 정답 단어
- 단어 시작 칸에 번호를 매기고, 가로 열쇠·세로 열쇠 목록으로 제시
- 모든 단어가 하나의 덩어리로 연결됨 (떨어진 섬 없음)

### 3.2 플레이 흐름

1. 퍼즐 목록에서 퍼즐 선택 → 퍼즐 화면 진입, 타이머 시작
2. 칸이나 열쇠를 눌러 단어 선택 → 해당 단어 칸 강조, 현재 열쇠 표시
   - 같은 칸을 다시 누르면 가로 ↔ 세로 전환
3. 입력창에 단어 전체를 입력 → [확인] → 그 단어를 바로 판정 (D6)
   - 맞음 → 격자에 채워지고 다음 단어로 이동
   - 틀림 → "틀렸어요"만 표시하고 입력창을 비움. 어느 글자가 틀렸는지는 알려주지 않고 격자에도 넣지 않음 (D11). 키보드는 열린 채라 바로 다시 입력할 수 있음
4. 모든 단어를 맞히면 완료 화면 (걸린 시간, 별점)

### 3.3 입력 규칙

- 입력창 위에 선택한 단어의 현재 상태를 패턴으로 표시 (예: `지 □ □ · 3글자`). 채워진 글자는 교차 단어를 맞혔거나 힌트로 연 칸이라 모두 정답
- 완성형 한글만 허용, 공백은 자동 제거. 미완성 자모(`ㄱ`, `ㅏ`)·영문·숫자가 섞이면 확인 불가 + 안내 (오답으로 치지 않음)
- 글자 수가 단어 길이와 다르면 확인 불가 + "3글자 단어예요" 안내 (부분 입력 없음, 오답으로 치지 않음)
- 형식 안내가 나올 때는 오답이 아니므로 입력창을 비우지 않음 (입력한 글자를 고쳐서 다시 확인)
- 격자에는 맞힌 글자만 들어가므로 덮어쓰기·지우기 기능이 없음
- 이미 맞힌 단어를 고르면 입력창 대신 "맞힌 단어예요" 표시

### 3.4 정답 판정

- 확인을 누를 때마다 그 단어 하나만 판정 (D6)
- 판정은 유니코드 정규화(NFC) 후 정답 단어와 비교
- 틀리면 "틀렸어요"만 표시하고 어느 글자가 틀렸는지는 알려주지 않음 (D11)
- 교차 단어를 맞히거나 힌트를 써서 칸이 모두 찬 단어도 맞힌 것으로 봄
- 흰 칸이 모두 차면(= 모든 단어를 맞히면) 완료

### 3.5 힌트

- 사용자가 고른 빈 칸 하나의 정답 글자만 공개 (단어 전체 공개 없음, D12). 채워진 칸은 이미 정답이라 고를 필요가 없음
- 모든 퍼즐에서 3회 고정 (격자가 커질수록 상대적으로 힌트가 귀해져 난이도 상승에 기여)
- 사용 여부는 별점에 반영

### 3.6 타이머·별점

- 퍼즐 화면에 경과 시간 표시. 화면을 떠나면(목록으로 나가기, 다른 탭·앱 전환) 일시정지, 돌아오면 이어서 측정
- 완료 시 별 1~3개 (목표 시간은 플레이 테스트로 보정)
  - ★★★ 힌트 없이 + 단계 목표 시간 이내
  - ★★ 힌트 없이 **또는** 목표 시간 이내 (둘 중 하나)
  - ★ 완료
- 퍼즐별 최고 기록(최다 별, 최단 시간) 저장, 다시 풀기 가능

## 4. 난이도 설계

### 4.1 단계별 구성

| 단계 | 이름 | 퍼즐 | 격자 | 단어 수 | 새로 등장하는 어휘 | 열쇠 구성 (%) |
|---|---|---|---|---|---|---|
| 1 | 입문 | 1~10 | 5×5 | 6~8 | 누구나 아는 구체 명사 | 뜻풀이 100 |
| 2 | 초급 | 11~20 | 6×6 | 8~10 | 생활 어휘 (장소·직업·물건·음식) | 뜻풀이 80 · 연상 20 |
| 3 | 중급 | 21~30 | 7×7 | 10~13 | 추상어·생활 한자어·외래어 | 뜻풀이 60 · 연상/빈칸 40 |
| 4 | 중상급 | 31~40 | 8×8 | 12~15 | 고유어 표현·개념어·고유명사·쉬운 사자성어 | 뜻풀이 40 · 연상/빈칸/상식 60 |
| 5 | 상급 | 41~50 | 9×9 | 14~18 | 사자성어·사회·역사·문화 상식 | 뜻풀이 30 · 연상/빈칸/상식 70 |

**완만한 곡선을 위한 규칙**

- 각 퍼즐은 자기 단계 등급 이하의 단어만 사용
- 2단계부터, 자기 단계 등급 단어 비율을 단계 안에서 퍼즐 번호가 오를수록 25% → 40%로 서서히 올림 (플레이 테스트로 보정)
- 단어 길이는 2~4음절 중심. 5음절 이상은 4단계부터 퍼즐당 2개 이내
- 필요한 정답 단어는 약 500~650개 → 후보 단어 은행 800~1,000개 확보

### 4.2 어휘 등급

모든 후보 단어에 등급 1~5를 매긴다.

| 등급 | 기준 | 예시 |
|---|---|---|
| 1 | 초등 저학년도 아는 구체 명사 | 사과, 기차, 우산, 나비, 연필, 바다, 고양이 |
| 2 | 매일 접하는 생활 어휘 | 소방관, 도서관, 냉장고, 무지개, 운동화, 신호등, 피아노 |
| 3 | 추상어·생활 한자어·흔한 외래어 | 추억, 약속, 환경, 경험, 습관, 명절, 스트레스 |
| 4 | 덜 쓰이지만 성인이 아는 고유어, 쉬운 개념어, 대표 고유명사, 아주 흔한 사자성어 | 소나기, 안간힘, 이웃사촌, 광합성, 한라산, 윷놀이, 작심삼일 |
| 5 | 사자성어, 사회·역사·문화 상식 | 동문서답, 우여곡절, 선견지명, 민주주의, 온난화, 훈민정음, 첨성대 |

**확장 어휘 등장 시점**

| 분류 | 등장 | 상한 |
|---|---|---|
| 흔한 외래어 | 1단계부터 | 외래어 표기법에 맞고 표기 혼동이 없는 것만 |
| 교과서 개념어 | 3단계부터 (초등 수준부터) | 성인 대부분이 학교에서 배워 들어본 것 |
| 상식 고유명사 | 4단계부터 | 지명·역사 인물·문화유산. 살아있는 인물·상표·기업 제외 |
| 쉬운 사자성어 | 4단계부터 | 일상 대화·뉴스에서 쓰이는 것 |

**판정 근거** — 1~3등급은 국립국어원 「한국어 학습용 어휘 목록」(2003, 약 6천 단어를 A·B·C 3등급으로 분류)이나 말뭉치 빈도 순위를 보조 자료로 삼고, 사자성어·고유명사·개념어는 별도 허용 목록을 만들어 사람이 검수한다 (Q5). 판단이 애매하면 한 등급 올리거나 뺀다 — 보수적으로.

### 4.3 제외 기준 — "너무 어려운 단어"

모든 단계에서 출제하지 않는다.

| 분류 | 예시 | 이유 |
|---|---|---|
| 옛말·방언·북한어 | 정구지(부추의 방언) | 표준어가 아님 |
| 분야 전문어 | 감가상각, 항소심, 부정맥 | 전문 지식 필요 |
| 드문 한자어 | 미증유, 효시, 질곡 | 성인도 뜻을 모르는 경우가 많음 |
| 드문 고유어 | 가납사니, 갈마들다 | 일상에서 거의 안 씀 |
| 신조어·유행어 | 갓생, 킹받다 | 금방 낡고 세대 차가 큼 |
| 비속어·차별·혐오 표현 | — | 부적절 |
| 살아있는 인물·상표·기업명 | — | 논란·상업성 위험 |
| 표기가 헷갈리는 단어 | 주스/쥬스, 초콜릿/초콜렛, 설거지/설겆이 | 뜻은 맞혀도 표기 때문에 오답 처리됨 |
| 띄어 쓰는 구 | 고양이 세수 | 칸에 띄어쓰기를 넣을 수 없음 |
| 동사·형용사 | 달리다, 아름답다 | 명사만 출제 (D14) |

### 4.4 열쇠 작성 기준

| 유형 | 예시 → 정답 | 등장 |
|---|---|---|
| 뜻풀이형 | 비 온 뒤 하늘에 뜨는 일곱 빛깔의 띠 → 무지개 | 1단계부터 |
| 연상형 | 백설공주, 뉴턴, 빨간 과일 → 사과 | 2단계부터 |
| 빈칸형 | (   )도 제 말 하면 온다 → 호랑이 | 3단계부터 |
| 상식형 | 한글을 만든 조선의 임금 → 세종대왕 | 4단계부터 |

**공통 규칙**

- 정답의 연속 2음절 이상을 열쇠에 쓰지 않음 (자동 검사)
- 한 문장 40자 이내 (휴대폰에서 두 줄 이내)
- 글자 수 + 교차 글자로 답이 하나로 좁혀져야 함. 1~2단계는 열쇠만으로도 답이 하나여야 함 ("빨간 과일" ✗ → 사과·딸기·앵두 모두 가능)
- 사전 뜻풀이를 그대로 옮기지 않고 새로 씀
- 상식형은 사실관계를 확인한 뒤 작성

### 4.5 주제 예시 (느슨한 주제)

퍼즐마다 주제 1개를 붙이고 퍼즐 목록·퍼즐 화면에 표시한다. 주제 단어는 전체의 약 절반(40~60%), 나머지는 해당 단계 일반 단어로 채운다.

| 단계 | 주제 후보 (확정 필요) |
|---|---|
| 1 | 과일, 동물, 탈것, 학교, 가족, 날씨, 몸, 바다, 장난감, 색깔 |
| 2 | 음식, 직업, 집안 물건, 운동, 계절, 우리 동네, 악기, 옷, 곤충, 채소 |
| 3 | 감정, 여행, 건강, 명절, 취미, 시장, 환경, 우주, 통신, 교통 |
| 4 | 전통 놀이, 비와 바람, 경제생활, 과학 시간, 산과 강, 몸과 마음, 직장 생활, 한국의 명소, 바다와 섬, 요리 |
| 5 | 사자성어, 역사 인물, 사회 시간, 문화유산, 문학, 세계 여러 나라, 예술, 속담, 과학 상식, 옛이야기 |

## 5. 기능 요구사항

| ID | 기능 | 내용 |
|---|---|---|
| FR-01 | 퍼즐 목록 | 단계별 10개씩 퍼즐 카드: 번호, 주제, 상태(안 풂·진행 중·완료), 별점, 최고 기록. 모든 퍼즐 선택 가능 |

## 7. 콘텐츠 요구사항

### CR-01 단어 은행

후보 800~1,000개. 단어마다 표기, 음절 수, 등급(1~5), 분류(고유어·한자어·외래어·사자성어·고유명사·개념어), 주제 태그, 열쇠와 열쇠 유형.

### CR-02 퍼즐

50개. 퍼즐마다 번호, 단계, 주제, 격자 크기, 단어 배치, 열쇠, 힌트 횟수, 목표 시간.

### CR-03 자동 검증 — 50개 전부 통과해야 배포

- [ ] 교차 칸 글자가 가로·세로 단어에서 일치
- [ ] 가로·세로로 2칸 이상 이어진 흰 칸 묶음은 모두 정답 단어 (의도하지 않은 단어 없음)
- [ ] 모든 단어가 하나로 연결
- [ ] 모든 칸이 완성형 한글 음절(가~힣)
- [ ] 퍼즐 안 중복 정답 없음, 같은 단계 안 재사용 없음, 전체에서 같은 정답 최대 2회 (D13)
- [ ] 단어 등급 ≤ 퍼즐 단계, 2단계부터 자기 단계 등급 비율 25~40%
- [ ] 격자 크기·단어 수가 §4.1 범위 안
- [ ] 주제 단어 비율 40~60%
- [ ] 열쇠에 정답의 연속 2음절 이상 미포함, 40자 이내
- [ ] 열쇠 유형 비율이 단계 전체 기준으로 §4.1 대비 ±10%p 이내

### CR-04 사람 검수

- [ ] 단어 목록: 단계별로 너무 어려운 단어가 없는지, 모두 명사인지
- [ ] 열쇠: 답이 하나로 좁혀지는지, 사실 오류가 없는지
- [ ] 플레이 테스트: 단계마다 2개 이상 직접 풀어 체감 난이도·풀이 시간 확인 → 목표 시간·등급 비율 보정

## 8. 사용자 스토리와 인수 조건

**US-1** 처음 하는 사람으로서, 1단계 퍼즐은 설명을 길게 읽지 않고도 바로 풀고 싶다.
- 1단계 단어는 모두 1등급, 열쇠는 모두 뜻풀이형
- 첫 실행 안내는 30초 안에 읽을 분량이고 건너뛸 수 있음

**US-2** 플레이어로서, 단계가 오를수록 조금씩 어려워지는 걸 느끼되 갑자기 막히고 싶지 않다.
- CR-03의 등급·열쇠 비율 검사 통과
- 플레이 테스트에서 단계별 평균 풀이 시간이 단계 순서대로 늘어나되, 이전 단계의 2배를 넘지 않음

**US-3** 휴대폰 사용자로서, 키보드로 단어를 칠 때 글자가 깨지거나 사라지지 않았으면 한다.
- NFR-03 기기 테스트 통과 (iOS 쿼티, Android 쿼티·천지인, PC 한글 입력기)

**US-4** 막힌 플레이어로서, 힌트로 한 글자를 보고 싶다.
- 힌트를 쓰면 선택한 칸의 정답이 보이고 고정됨, 남은 횟수가 줄고 0회가 되면 버튼 비활성

**US-5** 플레이어로서, 단어를 넣을 때마다 맞았는지 바로 알고 싶다.
- 확인을 누르면 맞음/틀림이 바로 보임
- 틀리면 "틀렸어요"만 보이고 어느 글자가 틀렸는지는 보이지 않음. 입력창은 비워지고 키보드는 열린 채라 바로 다시 입력할 수 있음
- 맞힌 단어만 격자에 채워짐

**US-6** 도전을 즐기는 플레이어로서, 힌트 없이 빨리 풀어 별 3개를 받고 싶다.
- 별점 규칙대로 부여, 최고 기록을 갱신하면 표시

**US-7** 플레이어로서, 중간에 앱을 꺼도 이어서 풀고 싶다.
- 새로고침 후 칸 상태·경과 시간·힌트 사용량이 그대로 복원

**US-8** 제작자로서, 데이터만 고쳐 퍼즐을 수정하거나 추가하고 싶다.
- 데이터 수정 → 자동 검증 통과 → 코드 수정 없이 반영

## 9. 이번 범위에서 제외

- 단어 풀이 카드(뜻·예문), 단계 순차 해금
- 다 채운 뒤 일괄 판정, 칸 직접 입력, 글자 타일 입력, 칸 지우기
- 로그인, 서버 저장, 랭킹, 공유
- 플레이할 때마다 새 퍼즐 자동 생성 (50개 고정)
- 광고·결제, 다국어 지원

## 10. 위험 요소

| 위험 | 영향 | 대응 방향 |
|---|---|---|
| 한글은 교차할 단어 찾기가 어려움 | 등급·주제 조건까지 걸면 격자 만들기가 막힘 (특히 5×5) | 단어 은행을 넉넉히, 느슨한 주제, 격자 생성 도구 + 사람이 다듬기 |
| 단어마다 바로 판정 | 확정된 글자를 바탕으로 이것저것 넣어 보며 맞히는 풀이가 가능 | 틀리면 입력창이 비워져 매번 다시 쳐야 하고, 시간이 별점에 반영되어 불리함. 오답 횟수를 별점에 넣을지는 플레이 테스트 뒤 판단 |
| 휴대폰 가상 키보드가 화면 절반을 가림 | 9×9 격자·열쇠·입력창이 한 화면에 안 들어감 | 키보드가 열릴 때의 레이아웃을 설계 단계에서 따로 정의 |
| 브라우저·자판마다 다른 한글 조합 동작 | 조합 중 Enter로 마지막 글자 유실·중복 | NFR-03 기기 테스트 목록으로 검증 |
| 열쇠가 모호함 | 답이 여러 개 → 억울한 오답 | 1~2단계는 열쇠만으로 유일하게, 사람 검수 |
| 상식형 열쇠의 사실 오류 | 게임 신뢰 하락 | 사실관계 확인 후 작성 |
| 난이도 체감이 계단식 | "조금씩"이 아니라 갑자기 어려워짐 | 단계 안 등급 비율 점진 상승, 플레이 테스트로 보정 |
